# G-OpenSteamTool v0.10.0

一键初始化现在会把通道数据一起做好：装完 DLL、写完默认 TOML 之后，直接为当前 Steam 构建生成 pattern 与 ipc 通道文件，不用再单独去通道页点。

## 新增

- **初始化部署通道数据**：`一键初始化` 依次完成安装 DLL、写入 `opensteamtool.toml`、生成 `pattern/steamui`、`pattern/steamclient`，以及（已记住 IDL 时）`ipc/steamclient`。
- **通道页新增「全部生成」**：侧栏一键刷新三条通道，结果提示会说明生成了几个、跳过了哪些及原因。
- **跳过不影响成功**：未选择 `IPCMessages.steamd` 时 ipc 会被跳过，pattern 两条照常写入，提示里明确写出原因，不会让初始化整体失败。
- **一次解析共用**：`steamclient64.dll` 只解析一次，pattern 与 ipc 共用同一份 PE 映像，初始化比分别生成更快。

## 实测

- 真实构建下：pattern 两条 + ipc 一条全部写出，与 `tools/pattern-tracker` 的 Python 流水线逐字节一致。
- 未给 IDL：写出 2 条 pattern，`skipped` 里是「ipc：尚未选择 IPCMessages.steamd」。
- 测试覆盖新增 `generate_all`：不带 IDL 时只跳过 ipc，带 IDL 时三条全出。
