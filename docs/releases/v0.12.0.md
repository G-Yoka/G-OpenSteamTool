# G-OpenSteamTool v0.12.0

`manifest.lua` 现在由应用托管了。

Steam 2026-09-09 起对 manifest 取码做账号归属校验，DLL 内置的 `opensteamtool` / `wudrm` / `steamrun` 三个源全部失效，客户端把失败显示成「无网络连接」。这一版把可用的取码链写进 `<Steam>/config/lua/manifest.lua`，并在设置页提供可复现的自检。

## 新增

- **下载通道托管**：设置页可写入 / 更新 / 移除 `<Steam>/config/lua/manifest.lua`，默认使用 ManifestDeX（`User-Agent: ManifestDeX/1.0`），自建端点可填在它前面。
- **下载通道自检**：按当前游戏探测自建端点、ManifestDeX 与三个旧源，再向 CDN 请求一次清单，直接显示 HTTP 状态、耗时与字节数。
- **`[manager]` 配置段**：保存托管开关与自建端点；DLL 忽略未知段。
- 默认 `manifest_url` 改为 `opensteamtool`；`validate_settings` 放行内置三个取值，并校验自建端点必须是 `http(s)://`。

## 边界

- 只管理带 `-- GOST-MANIFEST-LUA v1` 标记的文件；用户自管的 `manifest.lua` 不会被覆盖或删除。
- 应用不内置任何账号、密钥或取码服务；取码仍依赖外部服务或用户自建服务。
- 写入后需要重启 Steam 才会加载。
