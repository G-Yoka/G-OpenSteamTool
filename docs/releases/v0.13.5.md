# G-OpenSteamTool v0.13.5

「02 Depot 解密」认得出主体和 DLC 了，「03 Manifest」还是一片数字——这一版补齐。

## 改动

- Manifest 表新增**「归属」列**：每行标 `主体` / `DLC`，DLC 行悬浮给出对应 DLC AppId。
- 归属变化处插入**分组条**：`主内容` / `DLC · Escape Simulator 2: Apocalypse DLC`，右侧显示该组条目数（`32 条`、`2 条`）。
- 两张表共用同一份 `depot_ownership` 映射，选中配置后只读一次本地 `appinfo` / `packageinfo`，不额外解析。
- 查不到归属的行显示 `—`，不猜测。

## 验证

- 实机 2879840：Manifest 32+2 条按 `主体 / DLC · Escape Simulator 2: Apocalypse DLC` 分组，`4575721`、`4575722` 归入 DLC。
- `npx tsc --noEmit` 通过；`cargo test` 不受影响（lib 26 / 集成 38 / patterns 5）。
