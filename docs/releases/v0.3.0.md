# G-OpenSteamTool v0.3.0

v0.3.0 是一次完整的桌面体验、工程结构与本地 Depot 工作流升级。

## 便携版修复

- DLL 资源现已直接嵌入程序，单独下载并运行 `g-opensteamtool.exe` 时也可以使用“安装或修复”。
- MSI 与便携版使用相同的内嵌资源和 SHA-256 校验流程，不再依赖 EXE 外部的 `resources/dlls` 目录。

## 主要更新

- 全新 G-OpenSteamTool 图标，统一窗口标题栏、概览页、关于页、EXE 与 MSI 视觉。
- 新增 Steam 本地 Depot 自动发现：
  - 从 `appcache/appinfo.vdf` 获取 App 名称、Depot ID 与 Public Manifest GID。
  - 从 `config/config.vdf` 合并当前 Steam 环境已有的 Depot Key。
- Steam 目录自动检测并持久化，下次启动无需重复选择。
- 修复自定义窗口拖动、最小化和关闭按钮。
- Steam 关闭与重启移入后台任务，避免界面等待时无响应。
- Steam 未运行时不再先启动再关闭，避免“打开一次、关闭、再次打开”的重复流程。

## 工程与安全

- React 前端按 `app / features / shared` 分层。
- Rust 后端新增 `services` 应用服务边界。
- TOML、Lua 与安装清单使用带回滚的安全替换写入。
- DLL 仍通过 SHA-256 校验，只安全移除本工具管理且内容匹配的文件。
- Depot Key 仅本地读取，不写入应用日志。

## 精简内容

- 移除应用内在线更新、稳定版/测试版更新通道。
- 移除 GitHub 网络优化、DNS over TLS 与 DNS 延迟检测。
- 删除对应的前后端命令、Tauri 插件、权限和依赖。
- 后续版本通过 GitHub Releases 手动下载安装。

## 仓库结构

源码迁入 `app/`，文档集中到 `docs/`，界面预览集中到 `screenshots/`，与发布型项目结构保持一致。

## 下载

- `G-OpenSteamTool_0.3.0_x64_en-US.msi`：Windows x64 安装包。
- `g-opensteamtool.exe`：Windows x64 便携版。
- `SHA256SUMS.txt`：发布文件 SHA-256 校验值。
