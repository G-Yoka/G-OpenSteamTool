# G-OpenSteamTool v0.3.1

v0.3.1 完善本地 Depot 自动获取后的 Lua 条目生成。

## 更新内容

- 点击“本地自动获取”后，在已发现的 Depot 条目末尾自动追加当前游戏 App ID。
- 当前游戏 App ID 行不填写解锁标记与 Depot Key，保存后生成 `addappid(<AppId>)`。
- 如果自动发现的 Depot 中已经包含当前 App ID，则不会重复添加。
- Depot Key 与 Manifest 仍只从 Steam 本地 `config.vdf` 和 `appinfo.vdf` 读取。
- 延续 v0.3.0 的单文件便携模式，托管 DLL 资源已直接内嵌到 EXE。

示例：

```lua
addappid(4948001, 0, "030610fee4a0d13bbc99e06c4e90d278d6c68c3634a56305e2930c8883c9a63a")
addappid(4948000)
setManifestid(4948001, "1768210577221387288")
```
