# G-OpenSteamTool v0.7.3

v0.7.3 是界面重做后的第一个正式发布版：新增数据通道页与诊断页，补齐键盘操作与明暗主题，并把界面文案按「状态在前、机制在后」重排。

> v0.4.0 – v0.7.2 只作为本地迭代版本存在，未单独发布；本版包含这些迭代的全部改动。

## 新增

- **数据通道页**：按当前 Steam 构建的 SHA-256 展示 `pattern/steamui`、`pattern/steamclient`、`ipc/steamclient` 三个通道的安装状态、条目数与期望文件名，可直接安装 / 替换 / 移除。
- **诊断页**：读取 `Steam\dumps` 下的崩溃转储，把偏移归因到 `OpenSteamTool.dll` 或 Steam 侧；同时汇总缺失条目、被抑制的异常和旧键。
- **命令面板**：`Ctrl K` 打开，支持页面跳转与环境、组件、数据操作，输入即过滤。
- **快捷键**：`Ctrl 1…8` 直达导航、`Ctrl R` 刷新、`Ctrl F` 聚焦搜索、`Ctrl ⇧ L` 切换明暗主题、`?` 打开快捷键表。
- **明暗主题**：标题栏按钮或命令面板切换，首次启动跟随系统配色，选择写入本地存储并在首帧前生效。

## 改进

- 界面重做：指纹条 + 指标条 + 结论条的统一骨架，状态、组件、数据通道、诊断四页共用「结论在前、右侧下一步 + 最近日志」的读法。
- 数据通道页与组件页布局对齐，不再是通栏满宽卡片。
- 组件页区分「已加载」与「未加载 · 备用」；结论只以 `OpenSteamTool.dll` 是否被 Steam 加载为准，代理通道未触发不再误报为异常。
- 设置页新增 `[remote] url_template` 与 `[ui] suppress_missing_popup` 两项，并可直接调整四项网络超时。
- 界面文案精简：机制说明下沉到悬浮提示与文档，术语改为中文状态词，原始标识只保留在代码样式与提示里。
- 托管 DLL 资源体积从 11.0 MB 降到 1.44 MB，便携版仍是单文件内嵌资源，无需安装器。
